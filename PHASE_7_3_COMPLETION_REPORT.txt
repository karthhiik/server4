## Architecture Overview

### Service Architecture
```
TextureAtlas Service (textureAtlas.ts)
├── Public API
│   ├── getAtlas() - Create/retrieve atlas
│   ├── createMaterialFromAtlas() - Build materials
│   ├── updateMaterialUVMapping() - Apply UV coords
│   ├── getMemoryUsage() - Memory estimation
│   ├── getStatistics() - Performance metrics
│   └── disposeAtlas()/disposeAll() - Cleanup
│
├── Singleton Management
│   ├── getTextureAtlas() - Global accessor
│   └── resetTextureAtlas() - Reset/cleanup
│
└── Internal Methods
    ├── initializeGPULimits() - GPU detection
    ├── calculateTileSize() - Optimal dimensions
    ├── packTexturesIntoAtlas() - Combine textures
    └── createTextureFromSource() - Format conversion
```

### Component Integration
```
GlobeRenderer.tsx
├── getOrCreateGlobeTexture() [async]
│   ├── Try: getTextureAtlas() + create atlas
│   └── Catch: createGlobeTextureFallback()
└── useEffect cleanup: Dispose atlas refs

FunnelRenderer3D.tsx
├── useTextureAtlasOptimization() [hook]
│   ├── Initialize: getTextureAtlas()
│   ├── Log: statistics on mount
│   └── Cleanup: atlas refs on unmount
└── Scene component: Integrated hook
```
